# Formula Apex Spectator

Инжектор-скрипт для наблюдения за пилотами в игре **Formula Apex** (Roblox), совместимый с инжектором **Xeno v1.6**.

## Возможности
- 🏎️ Автоматическое отслеживание всех пилотов на сервере: скорость, состояние болида (HP).
- 💥 Детектор аварий (крашей): фиксирует момент, когда пилот разбил машину (резкое падение скорости + просадка здоровья).
- 📋 HUD-интерфейс прямо в игре со списком пилотов и логом последних аварий.
- ⏱️ Таймстемпы каждого инцидента — удобно для разборов в лигах.
- 🔗 Опциональная отправка событий об авариях в Discord через Webhook.
- Кнопка скрытия/показа интерфейса.

## Установка (Xeno v1.6)
1. Запустите Roblox и зайдите на сервер Formula Apex.
2. Откройте **Xeno v1.6** и сделайте **Attach** к процессу Roblox.
3. Скопируйте содержимое файла [`main.lua`](./main.lua) в редактор скриптов Xeno.
4. Нажмите **Execute**.

## Настройка
Все параметры находятся в таблице `CONFIG` в начале `main.lua`:

| Параметр | Описание |
|---|---|
| `REFRESH_INTERVAL` | Частота обновления данных пилотов (сек) |
| `CRASH_SPEED_THRESHOLD` | Порог скорости для детектора краша |
| `CRASH_DAMAGE_THRESHOLD` | Порог HP болида, ниже которого он считается разбитым |
| `MAX_LOG_ENTRIES` | Максимальный размер лога аварий |
| `WEBHOOK_ENABLED` / `WEBHOOK_URL` | Отправка событий в Discord |

## Примечание
Игра может обновляться — если имена моделей/атрибутов болидов изменятся,
адаптируйте функции `getCarForPlayer`, `getCarHealth` и `getCarVelocity`.
